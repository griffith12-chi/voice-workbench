变声整合包 · 使用说明
================================================================

一、这是什么
----------------------------------------------------------------
基于 RVC（Retrieval-based Voice Conversion）的便携整合包，自带 Python
运行环境、PyTorch、音频处理工具，以及四个操作界面。

本包不包含任何训练好的声音模型。模型需要单独放到“模型”文件夹里。

二、目录结构
----------------------------------------------------------------
  启动.bat               ← 双击这个
  RVC\                   运行环境（Python + PyTorch + ffmpeg + 预训练权重）
  工具\变声工作台\        拖文件转换
  工具\文字转语音\        文字转语音
  模型\                 放 .pth（和同名 .index）
  说明.txt

三、第一次使用
----------------------------------------------------------------
  1. 打开“模型”文件夹，把模型包里的 .pth 和 .index 复制进去
  2. 双击“启动.bat”
  3. 在窗口里选择需要的功能

  模型文件名建议用英文，部分底层库（faiss）读不了中文路径。

四、四个功能
----------------------------------------------------------------
【1】拖文件变声
   · 把 mp3 / wav / m4a / mp4 / mkv 拖进窗口（或点“添加文件”）
   · 在“模型”下拉框选择 .pth
   · 调“变调”，点“开始转换”
   · 结果在 工具\变声工作台\outputs\

   变调怎么设：
     0        保持原音高（男声转男声模型、自己录自己）
     -2 ~ -6  略低，男声转偏低音模型
     -12      降一个八度，女声转男声模型用
     -17 左右 高音女声转低音男声

   索引率：
     0       不用索引，最稳
     0.5     默认
     0.75+   更像训练目标，但毛刺会增加

【2】文字转语音
   · 输入文字 → 选模型和基础音色 → 点“生成语音”
   · 需要联网（使用微软 edge-tts）；断网会退回系统语音，音质明显变差
   · 注意：基础音色决定了语气和停顿，模型只换音色。
     

【3】实时变声
   · 选择输入设备（麦克风或虚拟声卡）和输出设备
   · 加载模型、设置变调，点 Start
   · 想喂给游戏 / Discord / 会议软件，需要虚拟声卡
     （推荐 Voicemeeter，本包不含，需单独安装）
   · 延迟大约 200-500ms，自己监听会明显感觉延迟，建议戴耳机

【4】训练模型
   · 打开 RVC 网页界面（浏览器访问 127.0.0.1:7897）
   · 基本流程：
       a. 准备 10-20 分钟干净人声（无背景音乐、无混响最好）
       b. 网页里“训练”页：填实验名 → 处理数据 → 提取特征
       c. 设置轮数（200 左右）、批大小（8GB 显存用 6）
       d. 训练 → 生成索引
       e. 训练好的模型在 RVC\assets\weights\，复制到“模型”文件夹即可使用
   · 8GB 显存可训练 40k 模型；数据越多越好，但 10 分钟以上收益递减
   · 训练时显卡会满载，建议不要同时做别的重活

五、系统要求
----------------------------------------------------------------
  · Windows 10 / 11 64 位
  · NVIDIA 显卡：推理 4GB 显存起，训练建议 8GB 起
  · 没有 N 卡也能用 CPU，但速度慢很多（转换一段 1 分钟音频可能要几分钟）
  · 内存 16GB 以上，磁盘预留 10GB

六、常见问题
----------------------------------------------------------------
  Q: 双击启动.bat 没反应？
  A: 看整合包根目录有没有“错误.log”，内容发出来即可定位。

  Q: 模型下拉框是空的？
  A: “模型”文件夹里没有 .pth，或文件名含中文导致扫描失败。

  Q: 转换时报 faiss 错误？
  A: 索引路径含中文。程序会自动复制到临时目录再读；仍然失败就换成纯英文路径。

  Q: 实时变声没声音？
  A: 依次检查：输入设备选对没有、Voicemeeter 路由、是否点了 Start、
     输出设备是否是虚拟声卡。

  Q: 训练界面打不开？
  A: 端口 7897 被占用。关掉旧的命令行窗口，或改用其他端口启动。

  Q: 杀毒软件报毒？
  A: PyTorch 和 Python 打包程序常见误报，加入信任即可。
