# 使用说明

## 这是什么

基于 RVC（Retrieval-based Voice Conversion）的便携整合包，自带 Python 运行环境、PyTorch、音频处理工具，以及四个操作界面。

发布包不包含任何训练好的声音模型。模型需要单独放到 `模型` 文件夹里。

## 目录结构

```
启动.bat                 双击启动
launcher.py              启动器
RVC\                     运行环境（Python + PyTorch + ffmpeg + 预训练权重）
tools\workbench\         拖文件变声
tools\tts\               文字转语音
模型\                    放 .pth（和同名 .index）
说明.txt                 本文档
```

## 第一次使用

1. 打开 `模型` 文件夹，把模型包里的 `.pth` 和 `.index` 复制进去
2. 双击 `启动.bat`
3. 在窗口里选择需要的功能

模型文件名建议用英文。部分底层库（faiss）读不了中文路径。

## 四个功能

### 1. 拖文件变声

- 把 `mp3 / wav / m4a / mp4 / mkv` 拖进窗口（或点「添加文件」）
- 在「模型」下拉框选择 `.pth`
- 调「变调」，点「开始转换」
- 结果在 `tools\workbench\outputs\`

变调对照：

| 场景 | pitch |
|---|---|
| 自己录 → 自己模型 | 0 |
| 男声 → 男声模型 | 0 ~ -6 |
| 女声 → 男声模型 | -12 |
| 高音女声 → 低音男声 | -17 左右 |

索引率：`0` 最稳，`0.5` 默认，`0.75+` 更像但毛刺增加。

### 2. 文字转语音

- 输入文字 → 选模型和基础音色 → 点「生成语音」
- 需要联网（微软 edge-tts）；断网会退回系统语音，音质明显变差
- 基础音色决定语气和停顿，模型只换音色
- 所以听起来像「用播音腔念稿」，而不是平时说话

### 3. 实时变声

- 选择输入设备（麦克风或虚拟声卡）和输出设备
- 加载模型、设置变调，点 Start
- 要喂给游戏 / Discord / 会议软件，需要虚拟声卡（如 Voicemeeter，本包不含）
- 延迟约 200–500 ms，自己监听会明显感觉延迟，建议戴耳机

### 4. 训练模型

打开 RVC 网页界面（`127.0.0.1:7897`）：

1. 准备 10–20 分钟干净人声（无 BGM、无混响最佳）
2. 「训练」页填实验名 → 处理数据 → 提取特征
3. 设置轮数（200 左右）、批大小（8 GB 显存用 6）
4. 训练 → 生成索引
5. 产物在 `RVC\assets\weights\`，复制到 `模型` 即可

数据越多越好，但 10 分钟以上收益递减。训练时显卡满载，别同时做重活。

## 常见问题

**双击启动.bat 没反应？**
看根目录有没有 `错误.log`，内容发出来即可定位。

**模型下拉框是空的？**
`模型` 文件夹里没有 `.pth`，或文件名含中文导致扫描失败。

**转换时报 faiss 错误？**
索引路径含中文。程序会自动复制到临时目录再读；仍然失败就换成纯英文路径。

**实时变声没声音？**
依次检查：输入设备是否选对、虚拟声卡路由、是否点了 Start、输出设备是否是虚拟声卡。

**训练界面打不开？**
端口 7897 被占用。关掉旧的命令行窗口，或改用其他端口启动。

**杀毒软件报毒？**
PyTorch 和 Python 打包程序常见误报，加入信任即可。
