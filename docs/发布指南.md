# 发布指南

两种方式，选一种即可。**方式 A 不需要安装 Git。**

---

## 方式 A：浏览器上传（推荐，最快）

### 1. 建仓库

GitHub 右上角 `+` → **New repository**

- Repository name: `voice-workbench`
- 选 **Public**
- **不要**勾 “Add a README file”（仓库必须为空）
- 点 Create repository

### 2. 上传代码

在新仓库页面点 **uploading an existing file**（或 `Add file` → `Upload files`）。

把 `E:\VoiceWorkbench\` 里的**所有文件和文件夹**拖进网页的拖放区：

```
README.md
LICENSE
.gitignore
启动.bat
launcher.py
说明.txt
RELEASE_NOTES.md
docs\
models\
screenshots\
tools\
```

底部 Commit changes → Commit directly to the `main` branch。

> 网页上传支持拖文件夹，会保留目录结构。

### 3. 创建 Release

仓库页右侧 **Releases** → **Draft a new release**

- Tag: `v1.0.0`
- Title: `v1.0.0 首个版本`
- Description: 把 `RELEASE_NOTES.md` 的内容粘进去
- 附件：上传 `E:\release\` 里的 **全部** `voice-workbench-v1.0.0.partN.rar`
- 点 **Publish release**

> 单个附件上限 2 GB，所以才会分卷。**必须全部上传**，缺一卷别人解压不了。

## 方式 B：命令行（需要 Git）

```bat
winget install --id Git.Git -e --source winget
```

装完重开终端：

```bat
cd /d E:\VoiceWorkbench
git config --global user.name "Griffith"
git config --global user.email "你的邮箱"
git init
git add .
git commit -m "feat: initial release"
git branch -M main
git remote add origin https://github.com/你的用户名/voice-workbench.git
git push -u origin main
```

密码处填 **Personal Access Token**：
GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token → 勾 `repo`。

## 发布前检查清单

- [ ] `git status --short` 或网页文件列表里**没有** `RVC/` 目录
- [ ] **没有** `.pth` / `.index` 模型文件
- [ ] `README.md` 里的链接和名称正确
- [ ] `LICENSE` 里的版权人是你的名字
- [ ] Release 的分卷**全部**上传（通常是 5 个）
- [ ] 在一个干净环境里下载解压测试过一次

## 关于模型

本仓库和 Release **都不包含训练好的声音模型**。

想分享模型时的建议：

- 不要放进公开仓库；模型一旦公开，任何人可合成你的声音
- 需要给特定的人，单独传 `.pth` + `.index`
- 若要托管，用 Hugging Face 的**私有**仓库

## 常见问题

**网页上传失败 / 卡住？**
文件多时改用方式 B，或分两次上传（先传代码，再传 docs 和 screenshots）。

**Release 上传到一半断掉？**
刷新页面重新上传断掉的那一卷，已上传的会保留。

**用户反映解压失败？**
多半是少下了一卷。在 Release 说明里写清楚“需下载全部 N 个分卷”。
